Devstral 2 is Mistral's current Devstral coding model for software-engineering agents, codebase exploration, tool use, and multi-file editing workflows.

## What this model is

Mistral's API pricing page lists the current pricing row as Devstral 2 with the model ID `devstral-medium-latest`. Mistral's model card lists Devstral 2 v25.12 with the API ID `devstral-2512`.

The Mistral pricing page describes Devstral 2 as an open-weights agentic coding model for autonomous software engineering. The model card marks Devstral 2 as OPEN and says it is for solving software-engineering tasks, including tool use, codebase exploration, editing multiple files, and powering software-engineering agents.

## Pricing notes

The calculator on this page uses Mistral's official API pricing row for Devstral 2 / `devstral-medium-latest`: $0.40 per 1M input tokens and $2.00 per 1M output tokens.

This is Mistral official API pricing, not an OpenRouter, cloud marketplace, or reseller route. The exact model-card ID checked is `devstral-2512`; the pricing page presents the current API pricing row under `devstral-medium-latest`.

## Best fit

Devstral 2 is best for Mistral API comparisons focused on coding agents, repository exploration, tool-using software engineering workflows, and multi-file editing.

For broader general assistant or multimodal work, compare against Mistral Medium 3.5. For lower-cost coding-agent experiments, compare against Devstral Small 2.

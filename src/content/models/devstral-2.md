Devstral 2 was Mistral's Devstral coding model for software-engineering agents. Mistral's current models overview lists it as retired. The last listed API price is kept here for historical comparison.

## What this model is

Mistral's models overview lists Devstral 2 v25.12 with API ID `devstral-2512` under Deprecated, with deprecation on 2026-05-22 and retirement on 2026-07-31. The listed alternative is Mistral Medium 3.5.

The earlier pricing page described Devstral 2 as an open-weights agentic coding model and showed the live pricing row as `devstral-medium-latest`. That live row is no longer present on the current Mistral API pricing page checked on 2026-08-25.

## Pricing notes

The calculator on this page keeps the last listed official Mistral API rates for Devstral 2 / `devstral-medium-latest`: $0.40 per 1M input tokens and $2.00 per 1M output tokens.

Treat those figures as historical last-listed prices, not as a current purchasable Mistral API route. For current Mistral coding and agent work, Mistral points to Mistral Medium 3.5.

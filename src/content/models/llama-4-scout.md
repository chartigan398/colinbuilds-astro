Llama 4 Scout is Meta's open-weight Llama-family model. It is one of the model ecosystems builders encounter most often when comparing open-weight and hosted API options.

## What this model is

Llama 4 Scout matters because it helps explain the difference between open-weight model availability and hosted API pricing. A builder can find hosted Llama routes through providers, but that is not the same thing as one official Meta pay-as-you-go API price.

## Pricing notes

No direct official Meta API price is shown on this page. Provider-hosted prices should be handled separately and labelled by provider, for example:

- Llama 4 Scout via OpenRouter
- Llama 4 Scout via Together
- Llama 4 Scout via Fireworks

That keeps the public page honest: Meta model profile here, provider pricing in provider-labelled comparisons.

## Best fit

- Explaining open-weight vs hosted API pricing
- Comparing Meta's model ecosystem with Qwen, Mistral, DeepSeek, and closed API models
- Beginner education around licences, providers, and deployment choices

Provider-hosted prices are not Meta official pricing. Open-weight availability does not automatically mean Apache/MIT-style open source.

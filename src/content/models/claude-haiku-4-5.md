Claude Haiku 4.5 is Anthropic's fast current Haiku-tier Claude model for API work where speed, price, and near-frontier capability matter more than choosing the largest Claude tier.

## What this model is

Anthropic's live models overview lists Claude Haiku 4.5 as the fastest current Claude model with near-frontier intelligence. The same table gives the Claude API ID as `claude-haiku-4-5-20251001` and the Claude API alias as `claude-haiku-4-5`.

Claude Haiku 4.5 is a closed/API model from Anthropic. Anthropic says current Claude models support text and image input, text output, multilingual capabilities, and vision.

## Pricing notes

The calculator on this page uses Anthropic's official model pricing row for Claude Haiku 4.5: $1 per 1M input tokens and $5 per 1M output tokens.

This is Anthropic official API pricing, not a cloud marketplace, reseller, or provider-hosted route. Anthropic also publishes separate prompt-cache and batch-pricing rows, but the main calculator fields here use the base input and output token prices from the model pricing table.

## Benchmarks and specs

Anthropic's models overview lists a 200k-token context window for Claude Haiku 4.5 and a July 2025 training-data cutoff. Anthropic does not publish a parameter count in the checked model overview, so no parameter field is stored here.

No benchmark score is shown until an exact benchmark source and model identity are matched to Claude Haiku 4.5.

## Best fit

Claude Haiku 4.5 is best for fast assistants, high-volume API calls, classification, extraction, lightweight agent steps, and multimodal tasks where official Anthropic pricing is required.

Use a larger Claude tier when the task needs the strongest reasoning or long-horizon coding performance rather than the Haiku speed-and-cost tradeoff.

Grok Build 0.1 is xAI's coding-focused API model for agentic software, engineering, and workflow tasks, exposed in the xAI docs under the exact model slug `grok-build-0.1`.

## What this model is

xAI lists the exact model name as `grok-build-0.1`. The model page describes it as an intelligent coding model for agentic software, engineering, and workflow tasks.

The official page lists text and image input with text output. It also lists function calling, structured outputs, and reasoning as capabilities, and shows aliases including `grok-code-fast-1`, `grok-code-fast`, and `grok-code-fast-1-0825`.

## Pricing notes

xAI's official Grok Build 0.1 model page lists API pricing at $1.00 per 1M input tokens, $0.20 per 1M cached input tokens, and $2.00 per 1M output tokens.

The calculator on this page uses the base uncached input and output rates: $1.00 input and $2.00 output per 1M tokens. xAI lists a 256,000-token context window and separately notes different rates for requests exceeding 200K context; exact higher-context rates are not included here, so long-context production estimates should check the xAI pricing page directly before budgeting.

## Benchmarks and specs

xAI's model page lists Grok Build 0.1 with a 256,000 token context window. It lists text and image input, text output, function calling, structured outputs, and reasoning.

This page does not show a parameter count or public benchmark score. Those numbers should only be shown when exact public sources are matched to `grok-build-0.1` specifically.

## Best fit

Grok Build 0.1 is best for builders who want xAI's coding-oriented API route for agentic coding workflows, software tasks, tool-using agents, structured-output coding helpers, and engineering assistants.

It is a different fit from a general flagship chat model: this page positions it around build and coding work, not as a broad replacement for every Grok route.

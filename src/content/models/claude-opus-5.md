Claude Opus 5 is Anthropic's current Opus-tier API model for complex agentic coding, enterprise work, and reasoning-heavy tasks. Anthropic's models overview says to start here if you are unsure which current Claude model to use for that class of work.

## What this model is

Anthropic lists the exact Claude API ID and alias as `claude-opus-5`. The current lineup table describes Opus 5 as the model for complex agentic coding and enterprise work, sitting between Sonnet 5 on cost/speed and Fable 5 on peak capability.

The same overview lists Claude Opus 5 with text and image input, text output, multilingual capability, vision support, adaptive thinking, a 1 million token context window, and a 128,000 token maximum output. Anthropic notes that every Claude model ID is a pinned snapshot.

Claude Opus 4.8 remains listed as a legacy model that is still available. This page is the current Opus API identity, not a rename of Opus 4.8.

## Pricing notes

Anthropic's official pricing page lists Claude Opus 5 at $5 per 1M input tokens and $25 per 1M output tokens. The calculator on this page uses those first-party Claude API rates.

The same pricing table lists prompt-cache rates for Claude Opus 5: 5-minute cache writes at $6.25 per 1M tokens, 1-hour cache writes at $10 per 1M tokens, and cache hits and refreshes at $0.50 per 1M tokens. Batch API discounts, cloud platforms, data residency, and regional endpoint premiums are separate.

## Benchmarks and specs

Anthropic's models overview lists Claude Opus 5 with a 1 million token context window, a 128,000 token maximum output, a reliable knowledge cutoff of May 2026, and a training data cutoff of May 2026. Retirement is listed as not sooner than July 24, 2027.

This page does not show a parameter count or public benchmark score. Those numbers should only be shown when exact public sources are matched to `claude-opus-5` specifically.

## Best fit

Claude Opus 5 is best for builders who need Anthropic's current high-capability Opus API model for complex coding agents, deep codebase work, enterprise assistants, difficult planning tasks, and long-context reasoning where answer quality matters more than lowest cost.

Sonnet 5 is the faster cost-balanced default. Fable 5 is Anthropic's higher-priced next-generation intelligence tier. Opus 4.8 is the previous Opus snapshot, still available as a legacy route.

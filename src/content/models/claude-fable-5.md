Claude Fable 5 is Anthropic's highest-capability current Claude API model, positioned for long-running agents and work where the extra cost over Opus 5 is justified.

## What this model is

Anthropic lists the exact Claude API ID and alias as `claude-fable-5`. The models overview describes Fable 5 as next-generation intelligence for long-running agents, and says to use it for the highest available capability in the current lineup.

The same overview lists Claude Fable 5 with text and image input, text output, multilingual capability, vision support, adaptive thinking that is always on, a 1 million token context window, and a 128,000 token maximum output. Default effort is listed as `high`.

Claude Mythos 5 appears on Anthropic's pricing table at the same $10/$50 token rates, but Anthropic marks Mythos 5 as limited availability. This page covers the generally listed Fable 5 API ID only.

## Pricing notes

Anthropic's official pricing page lists Claude Fable 5 at $10 per 1M input tokens and $50 per 1M output tokens. The calculator on this page uses those first-party Claude API rates.

The same pricing table lists prompt-cache rates for Claude Fable 5: 5-minute cache writes at $12.50 per 1M tokens, 1-hour cache writes at $20 per 1M tokens, and cache hits and refreshes at $1 per 1M tokens. Batch API discounts, cloud platforms, data residency, and regional endpoint premiums are separate.

## Benchmarks and specs

Anthropic's models overview lists Claude Fable 5 with a 1 million token context window, a 128,000 token maximum output, a reliable knowledge cutoff of January 2026, and a training data cutoff of January 2026. Retirement is listed as not sooner than June 9, 2027.

This page does not show a parameter count or public benchmark score. Those numbers should only be shown when exact public sources are matched to `claude-fable-5` specifically.

## Best fit

Claude Fable 5 is best when the job needs Anthropic's current top Claude API tier: long-running agents, the hardest reasoning or coding work, and quality-first enterprise tasks where Opus 5 is not enough.

For a cheaper default, use Sonnet 5. For complex agentic coding at the Opus price point, use Opus 5.

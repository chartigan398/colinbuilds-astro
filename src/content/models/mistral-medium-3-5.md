The calculator on this page uses Mistral's official API pricing row for Mistral Medium 3.5 / `mistral-medium-latest`: $1.50 per 1M input tokens and $7.50 per 1M output tokens.

This is Mistral official API pricing, not an OpenRouter, cloud marketplace, or reseller route. The exact model-card ID checked is `mistral-medium-3-5`; the pricing page presents the current API pricing row under `mistral-medium-latest`.
